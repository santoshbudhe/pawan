## Carousel standard

Before creating or modifying any website carousel, read:

`docs/design-system/carousel-standard.md`

Reuse:

`StandardCompactCarousel`

The approved default carousel is:

`SPC-01 — Standard Compact Carousel`

Do not create new section-specific carousel markup, typography or sizing when SPC-01 can support the requested content. Do not override SPC-01 styles inside a page component unless the user explicitly approves a new carousel variant.
