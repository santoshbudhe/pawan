# Build Rules

Never redesign approved layouts.

Never change spacing.

Never replace images.

Never hardcode colours.

Never hardcode typography.

Never hardcode spacing.

Always use reusable components.

Always use design tokens.

Always use Lucide icons.

Always use semantic HTML.

Always maintain visual parity with the approved desktop and mobile mocks.

---

# Success Criteria

The homepage should visually match the approved mockups.

Desktop and mobile should behave independently where specified.

No layout decisions should be invented by the developer.

All sections should be responsive.

Lighthouse Performance ≥95
